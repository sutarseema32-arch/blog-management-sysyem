# Blog Management System

A simple Blog Management System built using Core PHP, HTML, CSS, AJAX and jQuery.

## Features
- Add new blog posts with form validation.
- View blog posts in a datatable with delete option.
- Simple and lightweight.

## Installation
1. Clone or download the repository.
2. Import `blog_mgmt.sql` into your database.
3. Update `db_conn.php` with your DB credentials.
4. Open in browser: http://localhost/blog_mgmt/index.php

## Technologies
PHP, MySQL, jQuery, AJAX, HTML, CSS
